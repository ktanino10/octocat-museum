# みんなのオクトキャット美術館

GitHub × NEC のプログラミングワークショップに参加してくれた子どもたちが、
ひとりひとつずつ作った Octocat を集めた美術館です。

**→ https://ktanino10.github.io/octocat-museum/**

名刺の裏の QR コードを読むと、自分の作品のところから入館できます。

---

## 増えるほど、はっきりする

エントランスにある大きな Octocat は、参加した子の作品を1人1枚ずつ
タイルとして敷きつめて作っています。

タイルの数 = 参加した人数。

だから、参加する子が増えるほど Octocat の輪郭ははっきりしていきます。
いまはまだ少し粗いけれど、それは失敗ではなくて、
これから参加してくれる子の場所が空いている、ということです。

## 展示室

| | |
|---|---|
| HOME | 中央の Octocat と、参加チームの一覧 |
| HALL 01 | 2026年3月の参加者（20名） |
| HALL 02 | 2026年8月の参加者（22名） |
| TRIAL | GitHub の4択クイズ 10問 |
| MURAL | みんなのしるし（壁画）。TRIAL に合格すると開きます |

個別の展示では、作品を大きく、番号・名前・今日の職業・チームを添えています。

## ちょうせん（TRIAL）

GitHub についての4択クイズが10問。8問正解すると「ふういん」がとけて、

- ホームの中央が GitHub マークから **みんなのオクトキャット** に変わります
- 画面の色が変わります
- **MURAL（みんなのしるし）** が開きます。タイルを押すとその子の展示へ飛べます

まちがえても、何度でもやりなおせます。
問題も選択肢も毎回ならびかえるので、順番を覚えても意味がありません。

## このサイトについて

- ビルド不要の素の HTML / CSS / JavaScript です
- 画像とデータは `img/` と `data.json` にあります
- チームのマスコットは GitHub 公式の動くステッカーを WebP にしたものです
- 生成元のスクリプトは手元の作業フォルダにあります（名簿 + 画像 → サイト）
